Программа позволяет вычислить пропускную способность проезжей части улицы на перегоне, и определить пропускную способность одной полосы для разного набора коэффициентов при фиксированных значениях коэффициента торможения, а также произвести расчёт изменения пропускной способности проезжей части улицы на перегоне относительно скорости, и по полученным расчётам построить график.
